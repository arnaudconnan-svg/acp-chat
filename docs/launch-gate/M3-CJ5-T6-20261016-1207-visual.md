## Méthode et limites

La page urgence est le HTML/CSS/JS source exact, pas une reconstruction. Les empreintes [avant/après](evidence/M3-CJ5-T6-20261016-1207/visual/summary.json) permettent la comparaison avec les SHA Git. Le vrai module lib/emergency-resources.js produit les réponses API des fixtures synthétiques. Aucun serveur applicatif n'est démarré et le navigateur ne contacte pas la route de production.

Pour le lien depuis le chat, le HTML du vrai dialogue, ses styles et le gestionnaire de clic exact sont extraits de public/index.html. Seuls le profil et le stockage sont des doubles. Cela contrôle le composant et la navigation réelle dans Chromium, sans prétendre avoir exécuté l'authentification ou le chat complet avec fournisseurs.

La préparation Node est exécutée sous env -i et la garde M0 existante. Le contrôleur Python est aussi lancé sous env -i ; ses connexions socket sont refusées. Tous les contextes Chromium sont hors ligne, service workers bloqués et toutes les requêtes interceptées. Les **66 requêtes de contexte sont toutes satisfaites localement pour synthetic.example.test** ; aucune requête fournisseur n'est admise. Le navigateur emploie un profil temporaire fermé à la fin du parcours.

Un premier lancement a été bloqué avant rendu par un appel système local du gestionnaire de crash Chromium : [trace](evidence/M3-CJ5-T6-20261016-1207/visual/initial.log). La permission Shell native ponctuelle with_additional_permissions/network.enabled a ensuite permis les sockets internes du navigateur, sans modifier la politique native restricted/enforced, ni proxy, règle permanente ou accès complet. Le navigateur reste hors ligne et intercepté. La limite de chaque exécution graphique est 100 s. Aucun autre environnement n'a été créé.

Une fixture de dialogue initiale omettait l'encodage du document parent lors de l'extraction. Elle a été corrigée pour reprendre UTF-8 ; les captures finales du dialogue ont été refaites. Ce défaut de fixture n'a entraîné aucune modification de public/index.html.
